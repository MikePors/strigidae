# Contributing

Thanks for your interest in strigidae.

- Conventions, architecture, testing expectations, and the branch/PR workflow are in [CLAUDE.md](CLAUDE.md). It's written for both human and AI contributors, so please read it first.
- Find something to work on in the [issues](https://github.com/MikePors/strigidae/issues) or on the [project board](https://github.com/users/MikePors/projects/1).
- Run `make check` before opening a PR. It runs exactly what CI runs.
